Design a premium SaaS marketing website for Filmik, a production workflow platform built specifically for the film and television industry.

The overall aesthetic should feel modern, cinematic, premium and technology-forward, inspired by the visual language of Frame.io, Linear, Stripe, and Vercel, while maintaining Filmik’s own identity.

Use a dark interface with subtle gradients, generous spacing, rounded cards, soft shadows, and tasteful motion-ready layouts.

Visual Direction

* Similar color palette to Frame.io
    * charcoal backgrounds
    * dark slate surfaces
    * white typography
    * blue primary accent (#3B82F6 range)
    * subtle teal and indigo gradients
* Keep Filmik’s current typography (or Inter if unavailable)
* Use large bold headlines
* Lots of whitespace
* Minimalistic iconography
* Soft glassmorphism where appropriate
* Professional photography featuring film crews, stunt performers, production offices, cameras, monitors, and collaborative production environments
* Avoid generic stock business imagery

⸻

Design Style

The site should communicate:

Production software built specifically for the entertainment industry.

It should NOT feel like:

* generic project management software
* startup landing page
* waiting list website

Instead it should feel like:

“Enterprise software built for modern productions.”
