# Filmik Website

Marketing site for Filmik, built with Vite and React and deployed on Vercel.

## Current Status

- Local preview: `http://localhost:5173`
- Stable production URL: `https://filmik-website.vercel.app`
- Vercel project: `filmik-website`
- Deployment model: local changes are previewed first, then deployed to Vercel

## Stack

- Vite 6
- React 18
- TypeScript
- Tailwind CSS 4
- Radix UI primitives
- Motion for interactive effects

## Local Development

1. Install dependencies:

```bash
npm install
```

2. Start the local site:

```bash
npm run dev
```

3. Open:

```text
http://localhost:5173
```

## Build

Create a production build locally:

```bash
npm run build
```

This runs the SEO sync step before the Vite build.

## Request Access Form

The Request Access and newsletter forms are self-hosted and use Vercel functions. They never expose Mailchimp, Supabase, or Twilio credentials to the browser.

- Form components: [`src/app/components/RequestAccessModal.tsx`](/Users/victorfrias/dev/filmik-website/src/app/components/RequestAccessModal.tsx) and [`src/app/components/Footer.tsx`](/Users/victorfrias/dev/filmik-website/src/app/components/Footer.tsx)
- Server endpoints: [`api/request-access.js`](/Users/victorfrias/dev/filmik-website/api/request-access.js) and [`api/newsletter.js`](/Users/victorfrias/dev/filmik-website/api/newsletter.js)
- Shared delivery, validation, rate limiting, honeypot handling, Mailchimp, Supabase, and Twilio webhook logic: [`api/_lib/lead-service.js`](/Users/victorfrias/dev/filmik-website/api/_lib/lead-service.js)
- Required environment-variable names: [`.env.example`](/Users/victorfrias/dev/filmik-website/.env.example)
- Optional Supabase table: [`supabase/schema.sql`](/Users/victorfrias/dev/filmik-website/supabase/schema.sql)

### Form Behavior

- Every successful Request Access form is emailed to `info@filmik.io`, tagged in Mailchimp, and can be mirrored to Filmik's existing Twilio-backed in-app notification workflow.
- Marketing is opt-in: Request Access contacts are not subscribed to campaigns unless they select the update checkbox.
- Newsletter signups are tagged as `website` and `newsletter`, and use Mailchimp's `pending` status for confirmation before becoming marketing contacts.
- Supabase storage and the Twilio webhook are optional, but recommended for a durable lead record and staff alerting.

## Deployment Notes

### Production Release Gate

Before deploying to production, configure the required Mailchimp credentials in Vercel, verify delivery to `info@filmik.io`, and test the Mailchimp confirmation email. Do not publish the forms as active until these are confirmed.

Required Vercel environment variables:

- `MAILCHIMP_API_KEY`
- `MAILCHIMP_AUDIENCE_ID`
- `MAILCHIMP_TRANSACTIONAL_API_KEY`
- `LEAD_NOTIFICATION_EMAIL=info@filmik.io`

Optional Vercel environment variables:

- `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY`
- `TWILIO_ACCESS_REQUEST_WEBHOOK_URL` and `TWILIO_ACCESS_REQUEST_WEBHOOK_SECRET`

After running [`supabase/schema.sql`](/Users/victorfrias/dev/filmik-website/supabase/schema.sql), confirm the `service_role` has insert and select access to `public.website_leads`. The schema includes those grants; row-level security remains enabled and browser clients receive no direct table access.

### Lead Reports

Generate a report locally on demand using the server-only Supabase credentials:

```bash
pnpm dlx vercel env pull .env.local --environment=preview
pnpm leads:report
pnpm leads:report -- --format csv --out reports/website-leads.csv
pnpm leads:report -- --kind request-access --since 2026-09-01T00:00:00Z
```

The report is never exposed through the public website. It includes the submitted contact information, opt-in choice, referral source, and timestamp.

For a browser download, use `https://filmik-website-preview.vercel.app/api/reports/leads?format=csv`. The endpoint uses HTTP Basic Auth, returns `Cache-Control: no-store`, and never includes credentials in the URL. Use the configured report username and password. Add `kind=request-access` or `kind=newsletter`, and an optional ISO timestamp such as `since=2026-09-01T00:00:00Z`, to filter the report.

- Vercel config: [`vercel.json`](/Users/victorfrias/dev/filmik-website/vercel.json)
- Local Vercel linkage: `.vercel/project.json` (intentionally gitignored)
- Stable production alias should resolve to:
  - `https://filmik-website.vercel.app`

If the stable alias drifts after a deployment, correct the Vercel alias before considering the release complete.

- The repo now includes a dev container config at [.devcontainer/devcontainer.json](/Users/victorfrias/dev/filmik-website/.devcontainer/devcontainer.json)

As of August 20, 2026, GitHub documents that personal accounts include:

That makes it the cleanest free option for occasional remote updates on this marketing site.

### How To Use Codespaces

1. Open the repo on GitHub
2. Click `Code`
3. Open the `Codespaces` tab
4. Create a new codespace from `main`
5. Wait for setup to finish
6. Run `npm run dev`
7. Open the forwarded port for the site preview

### Notes

- If you stay within GitHub's included free quota, there is no added cost
- If you exceed the included free quota, GitHub may require billing before additional usage continues
- For this repo, shut down idle codespaces when you're done to preserve the free allowance
- Local work on this computer is unaffected
